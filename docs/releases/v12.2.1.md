# T-Zero v12.2.1 — Git hook safety fix

This patch fixes #43: installing or starting T-Zero no longer modifies Git hooks or `core.hooksPath`.

- Removed automatic star-reminder hook installation from package setup and the welcome banner.
- Made reminders opt-in: `python -m tzero.tzero_welcome --install-star-hooks`.
- The optional installer preserves existing hook managers and active hooks, never changes Git configuration, and rolls back partial writes on failure.
- Added regression coverage for local/global hook configuration, existing hooks, concurrent writes, installation failures, and linked worktrees.
- Synchronized the npm-bundled Python runtime and all package versions to 12.2.1.
- Updated the English and Turkish README star goal to 500.

## Publication

After this version is merged, successful CI on the current main commit creates its GitHub Release and dispatches npm, PyPI, VS Code/Open VSX, Hugging Face, and native-build publication workflows. Existing releases are left unchanged. Registry workflows report publishing failures explicitly.

## Upgrading

```sh
python -m pip install --upgrade tzero-mcp
npm install -g tzero-mcp@12.2.1
```

VS Code, Cursor, Windsurf, and VSCodium users can update the T-Zero extension through their extension marketplace.

## Repositories affected by older versions

Inspect `git config --show-origin --get-all core.hooksPath` and `.githooks/` first.
If T-Zero added the local `.githooks` setting, `git config --local --unset core.hooksPath` restores inherited/default hook lookup.
If it replaced a previous local setting, restore that original value or rerun the hook manager's installer. The previous value cannot be reconstructed automatically.
